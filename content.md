## 13. Design and Development Direction

### Visual Identity

- Warm, restrained neutral palette.
- Cream, warm beige, natural stone, taupe and charcoal.
- Elegant, readable typography.
- Generous whitespace.
- Strong architectural and interior photography.
- Minimal decorative elements.
- Refined, intentional transitions.

### Layout Guidance

- Flexbox for navigation, buttons and simple horizontal arrangements.
- CSS Grid for project galleries and structured content layouts.
- Responsive layouts for mobile, tablet and desktop.
- Reusable spacing, colour and typography variables.
- Consistent component styling.

### Image Direction

Use authentic interior photography, architectural details, furniture, material textures and approved 3D visualizations.

Placeholder imagery must be clearly separated from actual client work.

### Technical Priorities

- Semantic HTML.
- Mobile-first CSS.
- Organized SCSS architecture.
- Optimized WebP and AVIF images where appropriate.
- Responsive image delivery.
- Lazy loading for non-critical images.
- Appropriate image dimensions.
- Accessible forms and navigation.
- Search engine metadata.
- Open Graph metadata.
- Performance testing.
- Cross-browser testing.
